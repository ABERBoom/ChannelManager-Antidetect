# Channel Manager - Skill Documentation

## Tổng quan
Channel Manager là ứng dụng quản lý nhiều profile trình duyệt portable (Firefox, Chrome), cho phép:
- Tạo/xóa/sửa profile trình duyệt không giới hạn
- Đặt tên, gắn icon tùy chỉnh cho mỗi profile
- Mở nhiều trình duyệt cùng lúc, phân biệt rõ trên taskbar Windows
- Quản lý trạng thái (đang chạy/đã dừng) của từng profile
